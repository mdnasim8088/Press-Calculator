# ভাষা: English + বাংলা / আরবি

অ্যাপের **মূল লেখা সবসময় English।** প্রতিটা English লেখার নিচে ছোট করে একটা ব্যাখ্যা থাকে। ব্যাখ্যাটা **বাংলায়** নাকি **আরবিতে** দেখাবে, সেটা ব্যবহারকারী বেছে নেন।

## কোথা থেকে ভাষা বদলানো যায়

- **হোম পেজের উপরের ডান কোনায়:** `EN + [বাংলা | عربي]` বাটন
- **Settings পেজে:** "Help text language"

একবার বাছলে সেভ হয়ে থাকে, পরের বার অ্যাপ খুললেও একই ভাষা থাকে।

## ফাইলগুলো

| ফাইল | কী করে |
|---|---|
| `src/i18n/help.ts` | **সব বাংলা আর আরবি লেখা এক জায়গায়।** প্রতিটা লেখার একটা নাম (key) আছে, যেমন `"field.gap"`, আর তার `bn` আর `ar` দুইটা রূপ। |
| `src/components/ui/Help.tsx` | ছোট ব্যাখ্যার লাইনটা দেখায়। বেছে নেওয়া ভাষা অনুযায়ী বাংলা বা আরবি লেখা আনে। |
| `src/components/ui/LangToggle.tsx` | বাংলা / عربي বাছাইয়ের বাটন |
| `src/components/ui/FieldLabel.tsx` | English লেবেল + নিচে ছোট ব্যাখ্যা (Unit বাছাইয়ের মতো ঘরের জন্য) |
| `src/stores/settings.ts` | বেছে নেওয়া ভাষা সেভ রাখে (`helpLang`) |
| `src/app/layout.tsx` | বাংলা আর আরবি ফন্ট লোড করে (Noto Sans Bengali, Noto Sans Arabic) |

## নতুন লেখা যোগ করার নিয়ম

1. `src/i18n/help.ts`-এ নতুন key যোগ করুন, সাথে বাংলা আর আরবি দুইটা লেখা:
   ```ts
   "field.myField": { bn: "বাংলা লেখা", ar: "النص العربي" },
   ```
2. যেখানে দেখাতে চান, সেখানে লিখুন: `<Help k="field.myField" />`
3. ইনপুটের ক্ষেত্রে: `<NumberInput label="English label" help="field.myField" ... />`

**কোনো component-এ সরাসরি বাংলা বা আরবি লেখা লিখবেন না।** সব লেখা `help.ts`-এ থাকবে, যাতে দুই ভাষা সবসময় মিলে থাকে।

## লেখার মধ্যে মান বসানো

কিছু লেখায় সংখ্যা বসে, যেমন শেষ শিটের হিসাব:
```ts
"res.lastSheet": { bn: "শেষ শিট: {used} লেগেছে, {left} বাকি আছে", ar: "آخر ورقة: استُخدم {used}، والمتبقي {left}" }
```
```tsx
<Help k="res.lastSheet" vars={{ used: "27 cm", left: "73 cm" }} />
```

## কারেন্সি

কারেন্সি (ডিফল্ট **SAR**) Settings থেকে আসে, আর সব জায়গায় সেটাই দেখায়। অ্যাপের কোথাও "টাকা" বা অন্য কোনো কারেন্সি লেখা নেই।
