# থিম: রঙ, ফন্ট, ইফেক্ট

**সাদা ব্যাকগ্রাউন্ড, তার সাথে Fiverr-এর মতো সবুজ গ্রেডিয়েন্ট।** পেজের কাঠামো আর কোনা-কাটা "HUD" শেপ আগের মতোই আছে, শুধু রঙ বদলানো হয়েছে। Fiverr-এর কোনো লোগো বা নাম ব্যবহার করা হয়নি, শুধু রঙের ধরন নেওয়া হয়েছে।

> আগের থিম ছিল গাঢ় টিল আর সায়ান। সেটা ফেরত চাইলে git history-তে আছে।

## ফাইলগুলো

| ফাইল | কী আছে |
|---|---|
| `src/app/globals.css` | সব রঙ (CSS variable), গ্রেডিয়েন্ট, ছায়া, কোনা-কাটা শেপ, ভাসমান কণার অ্যানিমেশন |
| `src/app/layout.tsx` | ফন্ট লোড করা, আর ব্রাউজার বা ফোনের উপরের বারের রঙ (সাদা) |
| `src/app/manifest.ts` | ইনস্টল করা অ্যাপের রঙ (সাদা) |
| `scripts/build-brand.mjs` | Taghareed লোগো থেকে সাদা পেছন সরায় (লোগোর নিজের রঙ থাকে), আর পাখিটা কেটে আইকন বানায় |

**রঙ বদলাতে চাইলে শুধু এই ফাইলে মান বদলান।** পুরো অ্যাপে নিজে থেকে বদলে যাবে। কোনো component-এ রঙ সরাসরি লেখা নেই।

লোগোর রঙ বদলাতে হলে `scripts/build-brand.mjs`-এ রঙ বদলে চালান: `npm run brand`

## পড়ার সুবিধা (কনট্রাস্ট)

উজ্জ্বল Fiverr সবুজ (`#1DBF73`) সাদার উপর লেখা হিসেবে পড়তে কষ্ট হয় (2.4:1)। তাই:
- **লেখা আর বাটনে** একটু গাঢ় সবুজ: `#19A463` (3.2:1), গ্রেডিয়েন্ট শেষ হয় `#0A7A43`-এ (5.4:1)।
- **উজ্জ্বল সবুজ** শুধু সাজসজ্জায়: হালকা আভা, বড় হেডিংয়ের গ্রেডিয়েন্টের শুরু।
- সাধারণ লেখা: `#222325` (15.7:1), হালকা লেখা: `#62646A` (5.9:1)।

| class | কী করে |

| `glass` | সাদা কার্ড, বর্ডার আর হালকা ছায়া সহ |
