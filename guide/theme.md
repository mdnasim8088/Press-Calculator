# থিম: রঙ, ফন্ট, ইফেক্ট

রেফারেন্স ছবির মতো গাঢ় টিল "গেমিং HUD" স্টাইল। শুধু স্টাইলটা নেওয়া হয়েছে, কোনো গেমের লোগো বা ছবি নেওয়া হয়নি।

## ফাইলগুলো

| ফাইল | কী আছে |
|---|---|
| `src/app/globals.css` | সব রঙ (CSS variable), কাচের ইফেক্ট, গ্লো, কোনা-কাটা শেপ, ভাসমান কণার অ্যানিমেশন |
| `src/app/layout.tsx` | ফন্ট লোড করা (Google Fonts থেকে, `next/font` দিয়ে) |

## রঙ (`globals.css`-এর উপরে `:root`)

| নাম | রঙ | কোথায় |
|---|---|---|
| `--bg` | `#071216` | পুরো ব্যাকগ্রাউন্ড (প্রায় কালো টিল) |
| `--surface` | স্বচ্ছ গাঢ় টিল | প্যানেল/কার্ড |
| `--surface-2` | `#13303a` | ইনপুটের ঘর |
| `--border` | `#1e4450` | বর্ডার |
| `--accent` | `#38c6e0` | **মূল সায়ান রঙ**: বাটন, বড় সংখ্যা, সিলেক্ট করা মেনু |
| `--text` | `#e6f5f8` | লেখা |
| `--text-muted` | `#8aaab3` | হালকা লেখা/লেবেল |
| `--success` | সবুজ | Best layout, লাভ |
| `--warning` | হলুদ | শেষ শিটের বাকি অংশ |
| `--danger` | লাল | ভুল ইনপুট |

**রঙ বদলাতে চাইলে শুধু এই ফাইলে মান বদলান।** পুরো অ্যাপে নিজে থেকে বদলে যাবে। কোনো component-এ রঙ সরাসরি লেখা নেই।

Tailwind-এ এগুলো এই নামে ব্যবহার হয়: `bg-bg`, `bg-surface`, `text-accent`, `text-muted`, `border-border`, `text-warning` ইত্যাদি।

## ফন্ট

| ফন্ট | Tailwind class | কোথায় |
|---|---|---|
| **Orbitron** | `font-display` | বড় হেডিং, 01/02 নম্বর |
| **Rajdhani** | `font-ui` | মেনু, ট্যাব, লেবেল |
| **Inter** | `font-sans` (ডিফল্ট) | সাধারণ লেখা |
| **JetBrains Mono** | `font-mono` | সংখ্যা আর ফলাফল (অঙ্ক সোজা লাইনে থাকে) |

## বিশেষ ইফেক্ট (`globals.css`-এ `@utility`)

| class | কী করে |
|---|---|
| `glass` | ঝাপসা কাচের মতো প্যানেল |
| `glow` | চারপাশে নীল আলো |
| `text-glow` | লেখার চারপাশে নীল আলো |
| `hud-clip` / `hud-clip-sm` | উপরে-বাম আর নিচে-ডান কোনা কেটে দেওয়া (গেমিং লুক) |
| `no-scrollbar` | স্ক্রলবার লুকানো (মোবাইলের ট্যাবে) |
| `.particle` | ব্যাকগ্রাউন্ডে ভেসে ওঠা আলোর টুকরো |

## অ্যাক্সেসিবিলিটি

- ফোনে "reduce motion" চালু থাকলে সব অ্যানিমেশন আর কণা বন্ধ হয়ে যায়।
- বাটন কমপক্ষে 44px উঁচু, যাতে আঙুলে সহজে চাপা যায়।
- লেখা আর ব্যাকগ্রাউন্ডের রঙে যথেষ্ট পার্থক্য রাখা হয়েছে, যাতে পড়া সহজ হয়।
