# ফাইল গাইড: কোন ফাইলে কী আছে

এই ফোল্ডারে প্রজেক্টের প্রতিটা অংশের জন্য আলাদা `.md` ফাইল আছে। যে অংশ বুঝতে চান, সেই ফাইলটা খুলুন।

| গাইড ফাইল | কোন অংশ | এক কথায় |
|---|---|---|
| [backend.md](backend.md) | `src/core/` | সব হিসাবের নিয়ম (অঙ্ক)। অ্যাপের "মস্তিষ্ক"। |
| [frontend.md](frontend.md) | `src/app/`, `src/components/` | যা স্ক্রিনে দেখা যায়: পেজ, বাটন, ফর্ম। |
| [theme.md](theme.md) | `src/app/globals.css`, ফন্ট | রঙ, ফন্ট, গ্লো, ব্যাকগ্রাউন্ড। |
| [language.md](language.md) | `src/i18n/` | English + বাংলা/আরবি ছোট ব্যাখ্যা, ভাষা বদলানোর বাটন। |
| [data-storage.md](data-storage.md) | `src/stores/`, `src/lib/` | সেটিংস সেভ রাখা, সংখ্যা সাজানো। |
| [pwa.md](pwa.md) | `public/`, `manifest.ts` | ফোনে অ্যাপের মতো ইনস্টল আর অফলাইনে চলা। |
| [tests.md](tests.md) | `tests/` | হিসাব ঠিক আছে কিনা, তার অটোমেটিক পরীক্ষা। |
| [config.md](config.md) | রুট ফোল্ডারের ফাইল | প্রজেক্টের সেটিংস ফাইল (package.json ইত্যাদি)। |

## পুরো ফোল্ডার এক নজরে

```
D:\calculator-custom\
├── calculator.md        ← সব নিয়ম আর থিম (মূল প্রম্পট)
├── prompt.md            ← ধাপে ধাপে বিল্ড প্ল্যান
├── PROGRESS.md          ← কী কী কাজ শেষ হয়েছে
├── guide\               ← এই গাইডগুলো (কোন ফাইলে কী)
├── docs\                ← বিস্তারিত ডকুমেন্টেশন (১৭টা ফাইল)
├── src\
│   ├── core\            ← BACKEND: হিসাবের ইঞ্জিন
│   ├── app\             ← FRONTEND: পেজগুলো (প্রতিটা ফোল্ডার = একটা পেজ)
│   ├── components\      ← FRONTEND: পেজের টুকরো অংশ
│   ├── config\          ← মেনুর লিস্ট
│   ├── stores\          ← সেটিংস সেভ রাখা
│   └── lib\             ← ছোট সাহায্যকারী ফাংশন
├── public\              ← আইকন, অফলাইন ফাইল
└── tests\               ← হিসাবের টেস্ট
```

## সবচেয়ে গুরুত্বপূর্ণ নিয়ম

**হিসাব (`src/core/`) আর ডিজাইন (`src/app/`, `src/components/`) সম্পূর্ণ আলাদা।**
ডিজাইনের ফাইল শুধু হিসাবের ফাংশন ডাকে আর ফলাফল দেখায়, নিজে কোনো অঙ্ক করে না।
এই কারণে পরে মোবাইল অ্যাপ বানালে `src/core/` হুবহু আবার ব্যবহার করা যাবে।
