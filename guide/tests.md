# টেস্ট: হিসাব ঠিক আছে কিনা পরীক্ষা

টেস্ট হলো কোড দিয়ে কোড পরীক্ষা করা। প্রতিটা উদাহরণের সঠিক উত্তর আগে থেকে লেখা থাকে। কোড বদলালে টেস্ট চালিয়ে দেখা যায় কোনো হিসাব ভুল হয়ে গেল কিনা।

## ফাইলগুলো

| ফাইল | কী আছে |
|---|---|
| `tests/core.test.ts` | হিসাবের ইঞ্জিনের টেস্ট (১৭টা) |
| `tests/expression.test.ts` | সাধারণ ক্যালকুলেটরের টেস্ট (২০টা): `2+3×4 = 14`, `200+10% = 220`, ০ দিয়ে ভাগ দিলে ভুলের বার্তা ইত্যাদি |
| `tests/capacity.test.ts` | রোলে কয় পিস ধরবে তার টেস্ট (৬টা): 1 m × 5 m → 495, gap ছাড়া → 600, 5.5 m → 540 ইত্যাদি |
| `vitest.config.mts` | টেস্ট টুল (Vitest)-এর সেটিংস |

## কী কী পরীক্ষা হয়

| অংশ | পরীক্ষা |
|---|---|
| Units | 50 cm = 0.5 m, 1 inch = 25.4 mm, 1 ft = 30.48 cm |
| Area | 50×70 → 17.50 SAR, 150×150 → 112.50 SAR, 300×500 → 750 SAR |
| Packing | 100×100-এ 5×5 → 324 পিস, 1.5 cm বাকি, অপচয় 19% |
| Rotation | 100×50-এ 5×7 → ঘোরালে 117 পিস (সোজা 108) |
| Roll | 5×7, 500 পিস → 2.095 m, 104.75 SAR |
| Sheet | 5×5, 3000 পিস → 10 শিট, **73 cm বাকি**, 500 SAR / 463.50 SAR |
| Sheet | 5×7, 500 পিস → সমান হলে কম জায়গা লাগে এমন দিক বেছে নেয়, 85.5 cm বাকি |
| Sheet | একদম সমান ভরলে (648 পিস) কোনো আধা শিট থাকে না |
| Sheet | mm-এ দিলেও একই ফলাফল আসে |
| ভুল ইনপুট | স্টিকার শিটের চেয়ে বড় হলে ভুলের বার্তা দেয় |
| Profit | markup, margin আর লাভ |
